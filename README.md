# Yu-gi-oh Random Cards

Aplicação que implementa aleatoriamente cards de yu-gi-oh com seu nome e descrição.

### **Linguagens**
- Javascript
- Python

### **Bibliotecas**
- React.js
- Vite.js
- Three.js

**Executando o "server"**

`cd .\server\ `

`python api.py`

**Inicialize o front-end.**

`npm run dev`
